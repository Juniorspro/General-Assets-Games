# Música de los cinco mundos nuevos (generada con Higgsfield · sonilo_music)

Una canción por mundo, pedida con el clima de cada uno:

| archivo | mundo | idea |
|---|---|---|
| `nl_islas.mp3` | Islas Flotantes | pads suaves + arpegio pulsado, brisa de mar, mayor y esperanzado |
| `nl_acuario.mp3` | Acuario | pads sumergidos y apagados, campanas lentas, burbujeo |
| `nl_nubes.mp3` | Sobre las Nubes | pads tipo coro, campanitas brillantes, sin peso, mucha reverb |
| `nl_jardin.mp3` | Jardín de Vidrio | marimba y kalimba, cuerdas suaves, goteo de agua |
| `nl_tarde.mp3` | Atardecer | guitarra de nylon, piano eléctrico, olas, nostalgia dorada |

Salían de 95 s y 3,5 MB cada una en m4a. Para el juego se recortaron a **62 s** con fundido
de entrada (1,2 s) y de salida (1,5 s) — así el `loop` del `<audio>` no hace clic — y se
pasaron a **mp3 mono 64 kbps**: 485 KB cada una, 2,4 MB las cinco.
