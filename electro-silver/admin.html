Conectar con Supabase

Mientras tanto funciona igual. Sin conectar nada, el panel guarda las publicaciones en este navegador y la web las muestra. Sirve para probarlo, pero sólo las ve quien use esta computadora. Para que las vea todo el mundo hay que hacer los cuatro pasos de abajo, una sola vez.

1 · Crear el proyecto

Entrá a supabase.com, creá una cuenta gratis y después un proyecto nuevo. No pide tarjeta. Anotá la contraseña que te pide para la base, aunque no la vas a usar acá.

2 · Crear la tabla y el depósito de fotos

En el menú de la izquierda, SQL Editor → New query. Pegá esto entero y dale Run. Crea la tabla, el bucket de imágenes y los permisos: cualquiera puede leer, sólo vos podés escribir.

create table if not exists publicaciones (
  id           uuid primary key default gen_random_uuid(),
  creado       timestamptz not null default now(),
  titulo       text not null,
  detalle      text,
  precio       numeric,
  precio_antes numeric,
  cuotas       int  not null default 0,
  rubro        text,
  whatsapp     text,
  imagen_url   text,
  visible      boolean not null default true
);

alter table publicaciones enable row level security;

-- Leer: cualquiera, para que la web pueda mostrarlas
create policy "lectura publica" on publicaciones
  for select using (true);

-- Escribir: sólo con sesión iniciada
create policy "escribe el dueno" on publicaciones
  for all to authenticated using (true) with check (true);

-- Depósito de fotos, con lectura pública
insert into storage.buckets (id, name, public)
values ('publicaciones', 'publicaciones', true)
on conflict (id) do nothing;

create policy "fotos lectura publica" on storage.objects
  for select using (bucket_id = 'publicaciones');

create policy "fotos escribe el dueno" on storage.objects
  for insert to authenticated with check (bucket_id = 'publicaciones');

create policy "fotos borra el dueno" on storage.objects
  for delete to authenticated using (bucket_id = 'publicaciones');

3 · Crear tu usuario

Authentication → Users → Add user → Create new user. Poné un mail y una contraseña y tildá «Auto Confirm User». Ése es el usuario con el que vas a entrar acá.

4 · Pegar las dos claves

Están en Project Settings → API. La anon public es la que va acá: es pública a propósito y no da permiso de escribir, eso lo dan las reglas de arriba. La service_role no se pega nunca en una página.

Dónde queda cada cosa. La dirección y la clave anon quedan guardadas en este navegador para no pegarlas cada vez. La contraseña no se guarda: si cerrás la sesión, la pedimos de nuevo. Y aunque alguien abra esta página, sin usuario no puede publicar nada: las reglas del paso 2 lo impiden del lado del servidor.
