# H5 Game Presentation Patterns

These optional checks are for catching accidental generic web-page output. They
are not style rules, design recipes, or layout instructions. Use the user's
brief first.

## Result Check

Before finishing, verify:

1. The first screen belongs to the game experience.
2. Game state or gameplay feedback is visible.
3. At least one player action visibly changes the scene or state.
4. The player can enter or continue the game clearly.
5. Visible UI elements do not overlap each other or hide important game feedback.
6. On mobile, HUD and controls leave enough room to play.
7. The title/first screen works as the game's poster — the platform captures
   the cover from the first ~1.2s at 430×870 portrait.
8. Something is visibly alive on the first screen (idle motion counts); a
   static frame reads as a broken page.
